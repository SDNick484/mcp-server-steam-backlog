# mcp-server-steam-backlog

An MCP server for [Steam Backlog Triage](https://github.com/SDNick484/steam-backlog-triage):
ask Claude what to play next, search and filter your Steam library, and triage games into lanes
from any MCP client.

Work in progress. The interface it builds on is specified in
[`docs/backlog-api-contract.md`](docs/backlog-api-contract.md).
